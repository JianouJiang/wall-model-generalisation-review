# LaTeX template dependency

Obtain the Springer Nature LaTeX authoring template from the publisher's [LaTeX author support page](https://www.springernature.com/gp/authors/campaigns/latex-author-support). Install its complete distribution according to the included licence and instructions, and make `sn-jnl.cls` and `sn-nature.bst` available to LaTeX. A local copy of these two files may be placed in this directory; it is ignored by Git. The `latexmkrc` searches here.

The compiled PDFs in this repository were built with the template identified in the original project as version 3.1. The two files are third-party dependencies and are not part of this research export. A newer template may change pagination. This dependency is only needed to rebuild the manuscript; the scope analysis and figure reproduction run without it.
